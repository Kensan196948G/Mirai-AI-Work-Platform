# テスト計画

**文書状態：設計段階**  
**対象：Mirai AI ワークプラットフォーム Pilot**

## 1. 目的と範囲

本計画は、Chat、Work、Projects、Files、Agents、Tasks、Artifacts、Knowledge、Admin、DeepSeek API連携、新規10TB外付けHDD、監査、バックアップをPilot受入可能か検証するための試験項目を定める。日程、担当者、環境、実行結果は実施時に追記する。

## 2. 開始条件

- 対象ビルドと変更範囲が識別されている。
- テスト環境、テスト用Role、複数User/Projectが用意されている。
- 実Secretを含まないテストデータが承認されている。
- 10TB HDDを破壊しない障害試験方法と復旧手順がレビューされている。
- 別系統バックアップ先と復元先が準備されている。

## 3. 機能試験

| ID | シナリオ | 期待結果 |
|---|---|---|
| F-01 | 10ユーザーを作成し各Workspaceを利用 | 各ユーザーが独立して利用できる |
| F-02 | Project作成、メンバー追加、Role変更 | 許可操作だけ成功し監査される |
| F-03 | ChatでDeepSeek応答を取得 | 会話と利用量が対象ユーザー・Projectへ関連付く |
| F-04 | WorkからPlan、Task、Sandbox、Artifactを実行 | 状態遷移と成果物が追跡できる |
| F-05 | Upload、Download、Move、Delete | メタデータ、サイズ、checksum、監査が整合する |
| F-06 | AdminでQuota・状態・監査を確認 | Adminのみ実行でき変更が記録される |

## 4. 認証・認可・ファイル安全試験

| ID | 条件 | 期待結果 |
|---|---|---|
| S-01 | 未認証・期限切れセッションでAPI呼出し | 拒否される |
| S-02 | User AがUser BのIDを指定 | 内容を推測可能な形で返さず拒否される |
| S-03 | 未所属ProjectのURL/APIへ直接アクセス | 拒否され監査される |
| S-04 | `..`、絶対パス、symlinkで領域外を指定 | 保存・参照されない |
| S-05 | 拡張子偽装、過大ファイル、過多展開 | 検証ルールに従って拒否される |
| S-06 | Agentから他Workspace、host socket、Secretへ接続 | Sandbox境界で拒否される |

## 5. Quota・ストレージ試験

| ID | 条件 | 期待結果 |
|---|---|---|
| ST-01 | UUID指定mountと再起動 | `/mnt/storage` が期待する10TB HDDへmountされる |
| ST-02 | HDD未接続または未マウント | アプリ起動または書込みが停止し、ルートへ保存しない |
| ST-03 | read-onlyまたはI/Oエラー | Upload、Artifact、更新をfail-closedにし通知する |
| ST-04 | User/Project Quota直前・一致・超過 | 定義した境界で一貫して許可・拒否する |
| ST-05 | 使用率70/80/85/90/95% | 各注意、計画、警告、制限、緊急保護が作動する |
| ST-06 | 個別Quota内だが全体予備を侵食 | 全体保護制限を優先して拒否する |

危険な容量・切断試験は本番相当データを置かない検証環境で行い、事前に対象デバイスの型番、シリアル、UUIDを照合する。

## 6. 外部API・耐障害試験

- DeepSeek APIのtimeout、429、5xx、不正形式、途中切断を模擬し、再試行上限と利用者向けエラーを確認する。
- Tool結果の不正形式・過大出力を拒否または制限する。
- アプリ再起動後のJob状態、重複実行防止、監査相関を確認する。
- DBや監査保存の一時障害時に成功と誤表示しないことを確認する。

## 7. バックアップ復元試験

10TB HDDとは別媒体または別システムへ保存したバックアップから、隔離した復元先へDB、設定、重要Projectデータ、監査情報を復元する。件数、総バイト数、checksum、アプリからの参照、権限を照合する。元データを上書きせず、RPO/RTOは確定後に測定基準へ追加する。

## 8. 終了条件

- 必須試験が成功し、未実行理由がない。
- P1欠陥が0件で、P2の残存は承認済み対応計画を持つ。
- Security、データ隔離、fail-closed、復元の証跡がある。
- lint、test、build、セキュリティ検査の結果が対象ビルドへ紐付く。
- Pilot運用責任者が残存リスクを確認している。
