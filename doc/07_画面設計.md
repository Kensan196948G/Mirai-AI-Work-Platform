# Mirai AI ワークプラットフォーム 画面設計

**文書状態：設計段階**

## 1. 目的

本書は、Pilot向け画面の情報構造、画面一覧、主要操作、状態表示を定義する。完成した画面仕様ではなく、実装後に利用者試験とアクセシビリティ試験を行って確定する。

## 2. 共通レイアウト

```text
┌──────────────────────────────────────┐
│ 製品名／現在のProject／通知／利用者メニュー        │
├──────────┬───────────────────────────┤
│ Chat      │                           │
│ Work      │      主コンテンツ           │
│ Projects  │                           │
│ Files     │                           │
│ Agents    │                           │
│ Admin※    │                           │
├──────────┴───────────────────────────┤
│ 容量状態／接続状態／ヘルプ／実行中処理             │
└──────────────────────────────────────┘
```

`Admin` は権限を持つ利用者だけに表示するが、認可は必ずサーバー側でも行う。狭い画面では左ナビゲーションを開閉式にする。

## 4. ホーム画面

主要な次の操作を迷わず選べることを優先する。

- 「新しいChat」「新しいWork」の主要ボタン
- 実行中・確認待ち・失敗したWork
- 最近利用したProjectとファイル
- 自分と現在Projectの使用量
- ストレージやサービスの影響通知
- 初回利用者向けガイドへの導線

## 5. Chat詳細

メッセージ本文、役割、送信時刻、添付、モデル、エラーを区別して表示する。入力欄の近くに現在のProject文脈と添付先を常時表示し、誤ったProjectへの送信を防ぐ。送信中、中断、失敗、再試行、完了を視覚表現だけでなく文字でも示す。

## 6. Work詳細

Work詳細は次の区画で構成する。

1. Goalと制約
2. Planと承認状態
3. Taskの順序・進捗・担当エージェント
4. Tool実行の要約と危険操作の確認
5. Artifact一覧とプレビュー
6. Review、採用、再実行、終了

削除、公開、外部送信、権限変更などの確認画面では、対象、影響、取消可否を明示し、一般的な「実行しますか」だけにしない。

## 7. Files画面

保存先の個人・Project区分、現在パス、所有者、使用量を上部へ表示する。一覧には名前、種別、サイズ、所有者、更新日時、状態を設ける。アップロード中、検査中、利用可能、失敗、削除待ちを区別する。ドラッグ操作だけに依存せず、ボタンとキーボード操作を提供する。

## 8. 管理ダッシュボード

正常時の数字だけでなく、対応が必要な項目を上位へ表示する。

- `/mnt/storage` のマウント状態と期待UUID一致
- 実使用可能容量、使用量、空き容量、使用率、増加傾向
- 70／80／85／90／95%の段階
- I/O異常、読取り専用化、取得可能な健全性情報
- バックアップの最終成功と最終復元試験
- 実行中・待機中・失敗したエージェント
- 認証・権限・管理操作の異常

## 9. 状態とフィードバック

| 状態 | 表示要件 |
|---|---|
| 読込み中 | 対象範囲と進行中であることを文字で示す |
| 空 | 初回操作や条件解除への案内を示す |
| 成功 | 完了内容と次の行動を示す |
| 警告 | 影響、期限、推奨対応を示す |
| エラー | 利用者向け説明、再試行可否、追跡IDを示す |
| 権限拒否 | 不足権限と申請先を示し、存在を秘匿すべき対象は露出しない |
| ストレージ保護 | 新規書込み不可、既存データ参照可否、管理者対応中を示す |

## 10. 破壊的操作

削除、メンバー除外、容量縮小、Work中止は確認を必要とする。確認画面に対象名と影響を表示し、可能な場合は論理削除や取消猶予を設ける。大量操作では件数と対象条件を明示する。

## 11. レスポンシブ方針

Pilotではデスクトップを主対象とするが、主要な閲覧と緊急停止は小画面でも利用可能にする。表は横スクロールだけに頼らず、重要項目をカード化または優先表示する。タップ領域、ズーム、固定要素による遮蔽を確認する。
